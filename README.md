# 🚀 Nova Wallet

![Project](https://img.shields.io/badge/Project-Educational-blue)

## 📌 About This Project

Nova Wallet is a fictional cryptocurrency wallet-style dashboard built for learning and practicing front-end web development. The project focuses on UI/UX design, JavaScript functionality, and GitHub Pages deployment.

⚠️ **Note:** This project does not connect to any blockchain, does not store real funds, and does not represent any real cryptocurrency wallet. All balances and tokens shown are fictional and for illustration purposes only.

---

## ✨ Features

✅ Modern glassmorphism UI  
✅ Dark / Light theme switch  
✅ Editable profile
